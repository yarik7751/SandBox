# Подземелье — схема экранов

Фича: `feature/dungeon` (api + impl). Навигация — `JoyRouter`, экраны описаны в `feature/dungeon/api`.

## Экраны

| Экран | Route | Composable | ViewModel |
|---|---|---|---|
| Титульный | `dungeon` | `DungeonTitleScreen` | `DungeonTitleViewModel` |
| Интро уровня | `dungeon_intro?levelId={levelId}` | `DungeonIntroScreen` | `DungeonIntroViewModel` |
| Игра | `dungeon_game?levelId={levelId}` | `DungeonGameScreen` | `DungeonGameViewModel` |

## Диаграмма переходов

```mermaid
stateDiagram-v2
    [*] --> Title : вход в фичу

    Title : Титульный (dungeon)
    Title : «Начать» / «Уровни»\nсписок уровней с локами и рекордами
    Intro : Интро уровня (dungeon_intro)
    Intro : название, история, цель, пар
    Game : Игра (dungeon_game)
    Game : доска, статистика, панель персонажей,\nОтмена/Заново/Пауза/Звук

    Title --> Intro : «Начать» — первый непройденный\nразблокированный уровень
    Title --> Intro : клик по уровню в списке\n(незаблокированный)
    Title --> [*] : системная «назад»

    Intro --> Game : «Войти в подземелье»
    Intro --> Title : системная «назад»

    Game --> Game : Отмена / Заново
    Game --> Pause : «Пауза» / системная «назад»

    state Game {
        [*] --> Playing
        Playing --> Pause
        Pause --> Playing : «Продолжить» / тап по скриму
        Playing --> Win : победа\n(не последний уровень)
        Playing --> FinalWin : победа\n(последний уровень)
        Playing --> Lose : поражение

        state Win {
            [*] --> WinMenu
            WinMenu --> Intro : «Дальше» (levelId + 1)
            WinMenu --> Playing : «Ещё раз»
            WinMenu --> Title : «В меню»
        }
        state Lose {
            [*] --> LoseMenu
            LoseMenu --> Playing : «Ещё раз»
            LoseMenu --> Title : «В меню»
        }
        state FinalWin {
            [*] --> FinalMenu
            FinalMenu --> Title : «В меню»
        }
        state Pause {
            [*] --> PauseMenu
            PauseMenu --> PauseMenu : «Звук вкл/выкл», «Вибрация вкл/выкл»
            PauseMenu --> Playing : «Продолжить»
            PauseMenu --> Playing : «Заново» (рестарт уровня)
            PauseMenu --> Title : «В меню»
        }
    }
```

## Детали переходов

- **Титульный → Интро.** «Начать» открывает первый разблокированный уровень без рекорда, а если все пройдены — последний разблокированный. Список уровней показывается/скрывается кнопкой «Уровни» на том же экране; заблокированные уровни (выше `progress.unlockedLevel`) не кликаются.
- **Интро → Игра.** `levelId` берётся из аргумента навигации. Просмотр интро ничего не записывает — прогресс обновляется только по факту победы.
- **Игровое поле.** Над выходом — клетка улицы: герой начинает за стенами и входит через выход бесплатно (первый заход), пленник, дошедший до выхода, выходит автоматически. Панель персонажей под статистикой переключает активного (герой, освобождённые пленники): ходят тапом по клетке, двери переключает только герой. Победа — когда все пленники на улице и герой вышел через выход.
- **Прогресс.** Прогресс (разблокированный уровень, рекорды ходов) хранится через `DungeonProgressRepository` → `DungeonSaveLocalDataSource`. Победа на уровне N разблокирует N+1 и сохраняет рекорд.
- **Пауза.** Открывается кнопкой «Пауза» или системной «назад» (пока партия не окончена). «Заново» из паузы перезапускает тот же уровень без выхода с экрана. Тап по скриму = «Продолжить».
- **Победа.** Диалог «Победа»: статистика ходов/пар, «Новый рекорд!» при рекорде. «Дальше» ведёт в интро следующего уровня (через `Commands.OpenNext`), а не сразу в игру.
- **Поражение.** Причина поражения приходит из ядра (`core/dungeon`) в `OverUiModel.reason`.
- **Финал.** После победы на последнем уровне (`DungeonLevels.ALL.size`) показывается диалог «Подземелье пройдено», ведущий в меню.
